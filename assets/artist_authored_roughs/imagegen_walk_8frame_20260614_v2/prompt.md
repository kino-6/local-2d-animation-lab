# ImageGen Walk 8-Frame Rough v2

This source sheet is an AI-generated rough candidate for Route A.
It is not a human-authored final sprite.

## Prompt

Create an 8-frame side-view right-facing walk cycle sprite sheet for a 2D game character.

- Character: anime schoolgirl with pink bob hair, side profile, sailor-style white school top, red tie, navy pleated skirt, dark knee socks, brown shoes.
- Style: clean 2D game sprite art rough, cel-shaded anime, readable silhouette, slightly simplified game proportions, thick clean outline, limited shading, not painterly, not photorealistic.
- Layout: exactly eight full-body frames in a strict 4 columns by 2 rows grid. One centered full-body character per cell, same scale, same facing direction, generous padding.
- Motion phases: contact, down, passing, up, opposite contact, opposite down, opposite passing, opposite up.
- Background: perfectly flat solid `#00ff00` chroma-key background for background removal.
- Avoid: text, watermark, weapon, running pose, duplicate characters, crowd, geometric puppet look.

## Packaging

- source sheet: `source_sheet.png`
- split frames: `rough_frames/walk_000.png` through `rough_frames/walk_007.png`
- split note: each grid cell was cropped with a 5px inset to avoid grid seams.
- packaged output: `outputs/adoptable/artist_authored_8frame_walk_cleanup/`
- cleanup note: v2 required green-dominance chroma cleanup because the generated background was visually green but not perfectly uniform.

## Review

Compared with v1, this candidate is more game-readable:

- stronger outline;
- cleaner simplified silhouette;
- clearer contact/passing poses;
- less geometric puppet impression.

It is still a rough candidate, not production-ready art.

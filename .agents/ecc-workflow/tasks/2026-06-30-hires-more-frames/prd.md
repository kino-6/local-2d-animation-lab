# PRD

## Goal

Create a reviewable sprite-pack candidate with larger frame dimensions and increased animation
frame counts.

## Acceptance Criteria

- Build a non-destructive candidate under `outputs/adoptable/`.
- Increase frame canvas size beyond the current high-resolution candidate.
- Increase action frame counts by inserting deterministic in-between frames.
- Regenerate spritesheets, GIF/WebP previews, contact sheets, manifest/runtime metadata, and visual
  gate report.
- Run focused tests and visual gate checks.

# PRD

## Goal

Capture the new art-direction trauma cases and make the quality gate/report expose
them for sprite-pack production review.

## User Observations

- Sword and similar objects should be separated from the character body/effect layer.
- Some actions read as different characters.
- Jump character scale reads too small.
- Idle is too lazy/static.
- Clothing does not feel like it flutters across the animation set.

## Acceptance Criteria

- Add these cases to the historical visual trauma corpus.
- Add deterministic findings where practical, without pretending to solve subjective art direction fully.
- Re-run the improved gate on the current 1024 production candidate and record the result.
- Keep the existing pack files intact unless explicitly repairing them.
